# Forgetful Celeste

## Description

Celeste Giverny is a brilliant (but sometimes forgetful) developer. She leaves notes for herself everywhere.

Her GitHub profile is her personal billboard, but it's also her scratchpad.

Can you find what she left **unattended**?

---

## Category
- **GitHub / OSINT**

## Difficulty
- **Medium**

---

## Provided Links
👉 https://github.com/celeste-giverny

## Scenario

Celeste's GitHub profile looks like any other developer's: a profile page, a few repositories, some activity.

But Celeste writes notes to herself wherever she happens to be working, and she doesn't always clean up after herself.

Somewhere on her profile, a note she forgot about is still waiting to be found.

---

## Objective

Explore Celeste's GitHub presence and find the note she left behind.

Flag format: `THG{...}`

---

## Hints

- **Hint 1:** A GitHub profile is more than its front page. Look at everything she owns.
- **Hint 2:** Repositories aren't the only place developers jot things down on GitHub.
- **Hint 3:** What's on screen now isn't necessarily all she ever wrote.

---

## Goal

Track down Celeste's forgotten note and recover the flag.
